## 🏆 Pemenuhan Kriteria Penilaian

### 1. Struktur & Semantik HTML (Bobot 40%)
- **Tag Semantik Lengkap:** Menggunakan `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<figure>`, `<figcaption>`, `<time>`, `<address>`, dan `<footer>`.
- **Hierarki Heading yang Tepat:** Tepat satu `<h1>` utama di Hero, `<h2>` untuk setiap section, `<h3>` untuk kartu komponen, dan `<h4>` untuk sub-komponen.
- **Formulir Semantik & Aksesibel:** Menggunakan `<form>`, `<fieldset>`, `<legend>`, `<label for="...">`, serta input bertipe spesifik (`email`, `text`, `textarea`) dengan indikator validasi.
- **Aksesibilitas (a11y):** Dilengkapi *Skip Link*, teks alternatif `alt` pada semua gambar, atribut `aria-expanded`, `aria-label`, dan status `role`.

### 2. Penerapan CSS & Layouting (Bobot 30%)
- **100% CSS Murni (Bebas Framework):** Tanpa Bootstrap, Tailwind, atau pustaka CSS luar lainnya.
- **Sistem Desain Modern:** Menggunakan CSS Custom Properties (`:root` dan `[data-theme]`) dengan palet warna navy, biru aksen elektrik, slate, dan putih.
- **Tata Letak Fleksibel:** Mengombinasikan **CSS Grid** dan **Flexbox** untuk showcase proyek unggulan dan navigasi.
- **Tipografi:** Google Fonts *Plus Jakarta Sans* (body text) dan *Outfit* (headings).
- **Efek Visual:** Glassmorphism pada header, mikro-animasi pada hover kartu, dan floating badge.

### 3. Responsivitas Halaman (Bobot 30%)
- **Multi-Device Media Queries:**
  - **Desktop (> 1024px):** Tata letak grid lebar penuh, navigasi horizontal sticky.
  - **Tablet (768px - 1024px):** Tata letak teradaptasi dengan spasi optimal.
  - **Mobile (< 768px):** Menu drawer dengan hamburger animated, tata letak kartu satu kolom, dan tombol sentuh nyaman (touch-friendly minimum 44px).
  - **Small Mobile (< 480px):** Penyesuaian ukuran font dan padding kontainer.
